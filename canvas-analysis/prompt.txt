### 프로젝트 개요:
- 디스플레이 공정에서 원장 glass가 있고 그 안에 panel이 쪼개져서 그 panel이 200개면 200개의 모니터 디스플레이 패널이 나오고 그런 방식이야. 모델별로 panel의 개수가 다르지만 원장은 동일하게 때문에 모델 구분없이 원장 기준 분석을 하려고 함
- 불량정보는 x, y와 같은 좌표로 나오기 때문에, 어느 모델이든 panel을 grid로 쪼개서 분석 가능
- 사용자에게 N, M을 받아서, NxM의 grid로 쪼갤 것 (default는 10, 20)

### input data:
1. `defect.parquet` 
    - facility_code, part_no_name, inspection_end_ymdhms, defect_seq_no, product_id, panel_id, process_code, lot_id, model_code, pnl_latest_judgement_code, pnl_latest_summary_defect_term_name_s, def_latest_judgement_code, def_latest_summary_defect_term_name_s, def_pnt_x, def_pnt_y, def_pnt_g, def_pnt_d, def_size 컬럼 존재
    - def_pnt_x, def_pnt_y, def_pnt_g, def_pnt_d, def_size는 숫자로 변환 (float32)
    - inspection_end_ymdhms는 날짜로 변환 (현재의 포맷은 `yyyyMMddhhmmss`)
    - panel_id는 product_id를 포함. 따라서 panel_id - product_id = panel_addr  (product_id: ABCDEF, panel_id: ABCDEFA1, panel_addr: A1)

2. `pnl_map.parquet`
    - facility_code, part_no_name, pane_seq_no, use_flag, x_coordinate_value, y_coordinate_value, panel_location_info 컬럼이 있어. 여기서 panel_location_info는 defect.parquet의 panel_addr와 일치
    - x_coordinate_value, y_coordinate_value 는 숫자로 변환 (float32)
    - use_flag 'Y'값만 사용
    - 기본 필터는 facility_code, part_no_name로 조회
    - 모델별 원장내 패널의 4개 코너의 X, y좌표 정보를 포함. 예를 들어 패널이 50장이면 각 패널별 4 코너 정보이므로 200개의 데이터 존재
    - 원장은 중앙이 origin이므로 - ~ +값이 대칭으로 존재
    - 패널 끼리는 x,y 방향으로 모두 gap이 존재

### 요구사항:
- `input data`를 사용해서 defect정보의 x, y값을 패널 사이 갭을 제거하고 사용자의 그리드 정보를 받아 (N, M) 그리드로 쪼갠다.
- 쪼갠 그리드에 sub_panel_addr를 생성하여 컬럼에 추가; 규칙은 x, y라벨 모두 1~z (대문자 미포함), 방향은 둘 다 좌하단에서 우상단 가는 방향으로 숫자가 커짐
- 원본 x,y는 그대로 두고 gap을 제거했을 때의 x,y값을 컬럼에 추가
- heatmap을 그릴 때, panel_addr와 sub_panel_addr는 둘 다 두 자리고, 첫 번째가 x축 라벨, 두 번째로 y축 라벨을 만들고, y축 라벨의 경우는 아래에서 위로 숫자가 올라가도록 그린다.
- 위 기능을 fastapi로 제공 (multipart로 두 개의 데이터 받고, facility_code (required), N,M (default 값이 존재해서 optional) 받아오면 defect.parquet에 필요 컬럼 추가해서 반환)
- config.yaml 사용해서 N,M과 같은 변수들 default 값 지정하여 사용 (하드코딩 완전 제거)
- facility_code로 두 데이터 모두 필터를 하고, part_no_name으로 groupby해서 pnl_map 정보 조회하고 해당 정보로 gap제거하여 defect.parquet에 필요한 컬럼 추가한다.
- 개요, 소스트리, 기술스택 등 README.md 에 작성
- API.md에 API명세 서술
- 모든 문서는 한글로 작성

### preprocessing
- 날짜 변환
- 숫자 변환 (empty or null값도 처리)
- defect.parquet은 panel_addr를 만든다. 
- panel_addr는 두자리 문자이며, 첫 번째로 x축 라벨, 두 번째로 y축 라벨로 컬럼을 만든다.


### 개발스택:
- python 
- polars (pandas 완전 대체) - scan_parquet 사용할 것
- uv
- fastapi

### 검증 방법
- mock 데이터를 만들어서 (원장글래스 size: 1500 x 1800로 가정) 동작을 확인한다.
- 실제로 된건지 파악을 위해서, 개발 완료 시 scatter plot을 통해서 그림을 그린다. 
    - scatter의 점은 불량정보, 좌:pnl_map 데이터를 활용해서 직사각형의 패널의 border표시, 우: gap 제거한 뒤, 새롭게 정의된 패널로 grid표시 - 각 패널의 중앙엔 50% 투명도로 패널ID 넣을 것
    - heatmap은 좌: 원본 패널의 heatmap, 우: 새로 정의 된 heatmap
